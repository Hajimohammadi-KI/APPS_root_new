Evidence-based stop decisions

Product integration blocked by results

The CEFR abstention UI was not shipped

External accuracy was 11.7–16.1% on English and 21.6–26.9% on German reference documents, with substantial loss from every source-corpus result. None of the nine evaluations can retain 80% accuracy at 30% coverage under the measured confidence-threshold rule. This is cross-domain robustness evidence, not learner-proficiency validation. Exposing an answer/abstain UI now would convert a failed validation gate into a learner-facing feature. The correct product decision is no integration until an independent learner-writing validation set supports it; consequently no responsible teacher behavior review can yet start.
