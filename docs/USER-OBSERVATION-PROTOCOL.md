# Learner and teacher observation protocol

Status: ready to run; no human session is recorded as completed yet.

## Participants and privacy

Run five learner sessions and two teacher sessions. Obtain consent before recording task timings. Use participant codes `L01`–`L05` and `T01`–`T02`; do not record names, contact details, raw answers, audio, screen recordings, or document contents in the observation log.

## Learner tasks

1. Continue the recommended plan and explain why it is next.
2. Choose two Integrated Skills units with search and multi-select, apply them, and open one task.
3. Leave the task, use Back/Forward, and confirm the selected unit and draft are preserved.
4. Encounter a prepared recoverable service/PDF error and return through the recovery action.
5. Finish one repair task and locate the saved evidence.

## Teacher tasks

1. Open the review queue, identify one item needing correction, and inspect its evidence boundary.
2. Create one focused assignment by level, skill, and topic; review the original content and write learner-friendly instructions.
3. Link the review to its correction and next task.
4. Explain local export, import, and backup to a learner.

## Observation record

Record behavior by task, not general opinion:

| Field | Allowed values |
| --- | --- |
| Participant | L01–L05 or T01–T02 |
| Task | numbered task ID |
| Completed | yes / no |
| Time | seconds |
| Assistance | count |
| Backtracks | count |
| Wrong destination | count |
| Horizontal scroll needed | yes / no |
| Recovery succeeded | yes / no / N/A |
| Friction marker | concise interface observation without learner content |
| Next-task explanation (learner task 1 only) | correct / partly correct / incorrect / N/A |
| Multi-select comprehension (learner task 2 only) | independently completed / completed with assistance / not completed / N/A |

Stop a task after ten minutes or when the participant asks to stop. Do not coach unless the task is blocked; record each intervention as assistance.

## Decision rule

Do not call the flow successful from opinion alone. A task is successful only when the intended outcome is completed without essential horizontal scrolling and with no more than one facilitator intervention. Publish completion rate, median time, range, assistance count, and the three most frequent friction markers. Separately publish (a) how many learners correctly explained why the recommended task was next and (b) how many independently completed search, multi-select, Apply, and task opening. Do not infer those two comprehension outcomes from the overall task-completion rate. With seven sessions, treat results as directional product evidence rather than population estimates.
